# 第 1、2 步｜试玩与验收

更新：2026-09-10。交互线框与可玩原型完成；不是完整首版，也不是最终美术。

## 打开与试玩

- [可玩原型](http://localhost:5173/)：行囊 → 收拾好了 → 等它出门 → 点击窗边信夹 → 归来后看小竹垫。
- [交互线框](http://localhost:5173/outputs/wireframes/index.html)：两处场景/五种模拟状态，小铺/行囊/手账/设置路径。
- [独立测试版](http://localhost:5173/?debug=1)：单独存档，推进下一事件或模拟离线一天，不影响正常试玩。

首次确认后约 15 秒出发、60 秒来信、105 秒归来；加上操作约 2 分钟。第二趟恢复等待 2–5 分钟、旅行 2–4 小时。

当前仅道明竹乡、见闻“竹影里打个盹”、小竹垫、免费家常饭。盘缠初始 24，归来 +8。可重复出门，卡种仍为 1，纪念物数量累加；完整首版仍为九卡/六物。

## 已验证

| 范围 | 结果与方式 |
|---|---|
| 线框 | 浏览器点击两景、装包、旅行只读、小铺模拟扣款、来信阅读 |
| 真实时间首趟 | 实际等待备妥→出发→来信→归来，24→32 文，不是直接切状态 |
| 刷新恢复 | 旅行中/归来后刷新，状态与奖励保留；减少动效偏好保留 |
| 操作限制 | 实际取消不扣资源，旅行中吃食/用具禁改 |
| 离线 | 纯规则测试跨日追赶；浏览器测试钟模拟离线一天，只结算一趟 |
| 多窗口 | 第二标签只读，关闭原标签后自动接续，无重复入账 |
| 来信与收藏 | 1/9 种卡，多趟来信可逐封打开，重复卡不加卡种，纪念物单独计数 |
| 布局与键盘 | 360px 窄屏、1280px 桌面无横向溢出，当前按钮均至少 44px；弹层滚动、ESC 退出与焦点返回 |
| 自动检查 | 类型检查/生产构建通过；11 项规则与存档测试全部通过 |

自动测试覆盖时间边界、预留/取消/消耗、重复确认、离线重复推进、零盘缠保底、出发后拒绝改包、时间回拨、坏存档保护、存储降级、测试存档隔离。
