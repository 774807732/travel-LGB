# 第 1 步｜交互线框

可点击入口：同目录 `index.html`。使用演示状态，不写游戏存档。

| 页面/对象 | 入口 | 操作与返回 |
|---|---|---|
| 屋里/院坝 | 底部导航；侧门/家门 | 切换场景，导航保持常驻 |
| 行囊 | 布包或底部按钮 | 选择吃食/用具 → 原面板替换选择器 → 回行囊 → 收拾好了 |
| 已备妥 | 确认行囊 | 可重新选择/取消；自动离家由第 2 步实现 |
| 旅行中 | 侧栏模拟 | 空位替代角色与包；行囊只读；仍可看院坝、手账 |
| 小铺 | 院坝货架 | 买一份 → 就地反馈；不足时提示免费饭；关闭回院坝 |
| 来信 | 信夹或手账卡片 | 阅读即清未读；内容已入册；面板内进入手账 |
| 手账 | 底栏/陈列位 | 见闻、纪念物、旅程三个页签；九卡为最终首版目标 |
| 设置 | 顶部按钮 | 偏好和重置演示；重置在同面板内二次确认 |

交互约束：单层原生对话框、Escape 关闭、点击目标至少 44px、深层返回不叠弹层、实线热点/虚线环境分开。侧栏可以演示在家、备妥、旅行、来信、归来五种画面状态。

线框包含小铺、院坝等后续界面路径；第 2 步只实现一趟旅行所需部分，其余保留在此线框，不当作已完成游戏功能。
