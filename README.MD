## 关键架构

- Vite + React + TypeScript；`App.tsx` 交互，`components/Sheet.tsx` 单层原生弹窗，`styles.css` 画面。
- `content.ts` 为稳定内容 ID，`engine.ts` 为纯规则，`useGame.ts` 管时钟/单写入者，`storage.ts` 管存档。
- `walkable.ts` 管横竖版资源、地板、家具及绕行；`hop.ts` 按实际宽高比和 74px 步幅分跳；`ToadActor.tsx` 同步精灵/位移/影子并处理缩放；`App.tsx` 按 `layout + scene` 保存当页最后落脚点。
- `home → packed → traveling → home`；归来未读独立，不阻塞下一趟。奖励与历史在同一快照提交。
- localStorage 键保持 `travel-toad:v1` / `travel-toad:review:v1`，内部版本仍为 2；旧档补红苕稀饭库存 0，圆石数量/在途/历史迁移到琉璃熊猫，不重发奖励。
- 单写入者优先 Web Locks；HTTP 缺少该接口时用 IndexedDB 排他事务 + 12 秒租约、2 秒续约。每次写入在事务中核验权限并重读最新 localStorage，休眠旧页不能覆盖接替者。
- 只读页不写坏档备份；关闭原页后约 2 秒接续，异常退出或后台暂停时租约到期后接续。页面恢复重新取锁；不依赖 HTTP 下缺失的 `crypto.randomUUID`。
- 区分另一窗口占用与存储不可用；后者暂停操作、保留已有存档、提示允许存储后刷新，不再误报原窗口。`act / replace / advanceDebug` 返回 Promise，界面等待成功后再提示或关闭面板。
