# 旅行癞疙宝

更新：2026-09-11｜1.1 增加两景点地跳跃与家具碰撞；原定 P0 保持不变。

## 产品目标

四川乡野里的轻陪伴旅行游戏。安逸、有牵挂、克制憨趣；原创癞疙宝、场景和见闻，借鉴放置旅行的节奏。

- 1 主角、屋里/院坝 2 景、道明竹乡/成都坝坝茶/黄龙溪河街 3 地、9 张见闻、6 种纪念物。
- 3 吃食、2 永久用具、1 货币盘缠；收成 → 采购 → 装包 → 自行出门 → 来信 → 归来。
- 免费家常饭无限保底，可收齐全部内容。无饥饿、死亡、战斗、签到、广告、付费、社交。
- 首趟确认后 15 秒出门、60 秒信到、105 秒归来；后续等待 2–5 分钟、旅行 2–4 小时。
- 初始 24 文与一份成熟收成；每 4 小时产一份，每份 12 文，最多留 3 份；归来 +8 文。
- 吃食 8 文，用具 24 文。确认只预留，出门扣吃食，取消不耗；相同行囊重复确认不延迟。
- 物品影响路线倾向，不指定目的地；连续同地两次后换地方；每地未见卡、未收纪念物分别优先。
- 时间戳驱动离线结算，只完成已备好的一趟，不自动续行。
- 在家时两景都显示癞疙宝；点击空地会跳过去，家具、门槛、货架、信桩与簸箕不能落脚。位置是当次页面的表现状态，不写入旅行存档。

## API / 本地领域接口

没有后端 HTTP API，运行时不调用 AI。接口接收状态并返回新快照。

| 接口 | 职责 |
|---|---|
| `prepareTrip / cancelPreparation` | 配置、预留、取消行囊 |
| `advanceGame` | 按时间推进出发、来信、归来；固定结果并去重 |
| `routeWeights` | 吃食/用具倾向与连续重复保护 |
| `buyItem / harvest` | 采购、收成与盘缠 |
| `availableLetters / markLetterRead` | 来信列表与已读；读信不发奖 |
| `loadGame / saveGame` | 快照校验、迁移、自动备份及恢复 |
| `decodeSave / exportGame` | 导入检查、导出 JSON |
| `archiveBeforeReplace` | 主动替换前保留独立恢复备份 |
| `nextEventAt` | 测试时钟下一事件 |

## 关键架构

- Vite + React + TypeScript；`App.tsx` 交互，`components/Sheet.tsx` 单层原生弹窗，`styles.css` 画面。
- `content.ts` 为稳定内容 ID，`engine.ts` 为纯规则，`useGame.ts` 管时钟/单写入者，`storage.ts` 管存档。
- `walkable.ts` 用归一化场景多边形和阻挡矩形描述地板、家具碰撞；`App.tsx` 保存两景临时落脚点并触发跳跃。
- `home → packed → traveling → home`；归来未读独立，不阻塞下一趟。奖励与历史在同一快照提交。
- localStorage 键保持 `travel-toad:v1` / `travel-toad:review:v1`，内部版本升级为 2，自动接续旧原型。
- Web Locks 单写入者；其他窗口只查看，可翻页看景，原窗口离开后自动接续。
- `:backup` 有效快照；`:damaged` 异常原文；`:before-replace` 主动替换前备份。坏档不静默清空，保存失败明确提示。
- 声音为本地 Web Audio 合成，默认关闭；图像为内置生图工具制作的静态资产，网页端只加载 WebP。
- 不上传玩家进度、不跨设备同步。清浏览器数据或换网址前请导出；localhost、127.0.0.1 和正式域名各有独立存档。
- 构建发布为私密静态站点；无数据库、账户系统或密钥需求。

每次任务结束前同步本文件、`DESIGN.MD`、`MAPPING.MD`、`HANDOF.MD`。前期方案保留设计假设，实际进度以交接与验收记录为准。
